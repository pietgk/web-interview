Agreed policy

Agreed

Risk-tiered, not blanket

Target semantic dates, nontrivial behavior and representation numbers, and configured contracts. Keep evident structural outcomes readable.

Agreed

Meaning owns location

Scenario constants stay local. Shared constants exist only when consumers depend on the same invariant, never merely the same primitive value.

Agreed

Highest semantic level

Expose ULID_LENGTH for width consumers and EARLIEST_ULID for stale transaction or cursor scenarios. Callers do not reconstruct the latter.

Agreed

Hard errors, no auto-fix

Messages explain the required reasoning. Authors choose names and sources. Safe fixes may be added later only with focused proof.

Implementation shape

Rule tests

Prove named literals, structural outcomes, canonical references, ambiguity failures, and exemptions.

Generic plugin

Repository-local AST rules implement mechanisms without Todo-specific values embedded in traversal code.

Declarative config

Patterns, denied names, contract modules and exports, usage mappings, and narrow data-file exemptions live centrally.

Atomic migration

Fix every configured violation, document the policy, enable error severity, and run the full verification gate.

Documentation and safeguards

  • Naming quality: require category-bearing names and reject generic placeholders, while acknowledging lint cannot prove human-level semantics.
  • False positives: allow only central, narrow exemptions for data-dense numeric or geometry files. Inline disables remain forbidden.
  • Contract drift: mappings point to module exports and syntax contexts, never primitive values such as 1000.
  • Policy discovery: add a concise rule to AGENTS.md, a full docs/semantic-constants.md standard, and rule-local examples. No ADR or Todo glossary entry.
