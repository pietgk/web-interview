Recommended now

Compatibility-first TypeScript 7 upgrade

  • Pin typescript@7.0.2 in the repository.
  • Set strict: false explicitly because TypeScript 7 defaults it to true.
  • Set maxNodeModuleJsDepth: 0 so untyped dependency source is not checked.
  • Enable vtsls.autoUseWorkspaceTsdk in Zed.
  • Annotate three void-returning IndexedDB promises.
Separate follow-up

Strict mode adoption

  • Do not mix full strict mode into the compiler upgrade.
  • Current TypeScript 7 defaults produce hundreds of diagnostics.
  • Enable stricter flags per project after declarations and public contracts are stable.
  • Start with strictNullChecks in shared because Zod inference depends on it.

Why not expose the declarations emitted today?

The current declaration emit completes, but it includes test files, leaks many any types, and describes required Zod fields as optional because strictNullChecks is disabled. Those files would silence Zed while weakening the actual package contract.

Implementation sequence

Align compiler and editor

Upgrade the root compiler, add explicit compatibility defaults, update Zed settings, and fix the three Promise annotations.

Exit: CLI and Zed both use 7.0.2; all four current checks pass.

Strengthen shared source types

Enable strictNullChecks for shared and type every exported function, class, storage interface, transaction, database, actor event, and snapshot that currently emits any.

Exit: generated public declarations contain intentional types and required Zod fields.

Add a declaration-only build

{
  "extends": "./jsconfig.json",
  "compilerOptions": {
    "noEmit": false,
    "declaration": true,
    "declarationMap": true,
    "emitDeclarationOnly": true,
    "rootDir": "src",
    "outDir": "dist/types",
    "strictNullChecks": true
  },
  "include": ["src/**/*.js"],
  "exclude": ["src/**/*.test.js"]
}
Exit: only production declarations and maps appear under dist/types.

Publish typed export conditions

"./contract": {
  "types": "./dist/types/todoContract.d.ts",
  "default": "./src/todoContract.js"
}

Repeat for actor, database, protocol, selectors, and transactions. Keep the types condition first.

Exit: consumers resolve declarations while Node and Vite continue to execute JavaScript.

Automate and verify

Add build:types and watch scripts, build declarations before consumer typechecks, include them in the packed package, and run a small consumer compilation against every export.

Exit: generated files are reproducible and cannot drift from source.

Artifact policy

Do not hand-edit generated .d.ts files. For this private monorepo, keep dist/types generated and ignored, build it during setup and CI, and let aligned TypeScript/Zed inspect workspace source during development. If the package is later distributed without a build step, publish or commit the generated artifacts as part of that release workflow.
